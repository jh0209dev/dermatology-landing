# 피부과 랜딩페이지

한국어 피부과 안내용 단일 페이지입니다. 진료 철학, 주요 피부 고민, 첫 방문 흐름, 내원 정보, 자주 묻는 질문을 담았습니다. 병원명·지역·주소·진료 시간·연락처처럼 대괄호로 표시한 항목은 실제 정보로 바꿔 주세요.

## 로컬에서 보기

Python 3가 설치되어 있으면 프로젝트 폴더에서 다음 명령을 실행합니다.

```sh
python3 -m http.server 4173 --directory dist
```

브라우저에서 [http://localhost:4173](http://localhost:4173)을 엽니다. 별도 패키지 설치나 빌드 과정은 없습니다.

## 파일 안내

- `index.html`: 페이지 원본
- `dist/index.html`: 로컬 서버에서 제공하는 정적 페이지
- `.openai/hosting.json`: Sites 프로젝트 식별 및 정적 파일 경로 설정

페이지는 사진과 웹폰트를 Unsplash 및 Google Fonts에서 불러오므로 해당 리소스 표시에는 인터넷 연결이 필요합니다.
